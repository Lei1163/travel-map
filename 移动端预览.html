赴迹 · 移动端预览

下面是真实运行的 app，只是被装进了手机尺寸的窗口里 —— 可以点、可以拖、可以缩

手机上的操作方式

  1. 左上角 ☰ 菜单：滑出「旅程足迹」侧栏，点空白处收起
  2. 顶部「国内 / 国际」：切换两张互不相干的地图
  3. 单指拖动：平移地图；双指捏合：放大 / 缩小（电脑上用滚轮）
  4. 点城市圆点：弹出该地点的记录卡片（照片 / 手记 / 日期）
  5. ＋ 添加一段新足迹：选城市 → 填日期 → 存成一段旅程
  6. 右上角分享图标：生成国内 / 国际两张分享图

小屏（≤760px）时：地图上的城市名只显示选中的那一个；缩放按钮和底部图例自动隐藏； 记录卡片变成从底部弹出的抽屉，照片网格固定 3 列。

想在真机上体验：把这个文件夹（或 赴迹.html）发到手机， 用 Chrome / Safari 打开即可，布局会自动切成手机版。
